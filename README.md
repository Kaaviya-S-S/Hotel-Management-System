This Hotel Management System is built using Object-Oriented Programming (OOP) principles in C++. It efficiently manages hotel operations such as room bookings, room assignments, customer records, and billing processes. The system ensures streamlined operations and provides organized file management for customer and room data.

<h6>**Key Features:**</h6>
**Room Booking**: Allows customers to book rooms based on availability and preferences.  
**Room Assignment**: Automatically assigns rooms based on customer needs (e.g., room type).  
**Customer Records**: Stores and manages customer details for easy access.  
**Billing System**: Generates and manages customer bills, ensuring accurate financial records.
